# 校园易援云端部署

核验日期：2026-09-30（Asia/Shanghai）。此记录描述当日部署结果，不保证后续服务状态。

## 当前结果

- 腾讯云轻量应用服务器：106.52.127.171，Ubuntu 24.04.4。
- Java 17、MySQL 8.0、Nginx 已安装。
- 后端 jar 位于 `/opt/campushelp/app.jar`，服务名 `campushelp`。
- MySQL 数据库 `campus_help`，业务数据库账号 `campushelp`。
- 数据库密码由服务器生成，保存在 `/etc/campushelp/backend.env`，文件权限 600；不包含在源码中。
- 订单照片目录 `/var/lib/campushelp/uploads`。
- Java、MySQL 仅监听本机地址；Nginx 提供健康检查。
- `api.xyyy.online` 的 A 记录已解析到服务器；Let's Encrypt 证书已签发，到期日为 2026-12-28，续期定时任务已启用。
- Nginx 已监听 443，服务器本机的 HTTPS 健康检查通过。腾讯云防火墙放行后，公网 TCP 443 可连接，但使用域名发起 TLS 握手时连接被重置；通过公网 IP 且跳过证书校验的测试可返回健康检查。尚不能用于微信小程序，请检查域名审核/备案与腾讯云平台限制。
- 公网 HTTP 的 `http://106.52.127.171/api/health` 可用于健康检查；域名 HTTP 会跳转到 HTTPS。
- 业务 API 目前返回 503，待备案、真机和短信方案明确后开放。
- 后端、MySQL、Nginx 配置为开机启动。
- 云端数据库为新建数据库，没有复制电脑上的账号、订单或用户照片。
- 云端 `DEMO_CODES_ENABLED=false`：验证码接口返回尚未配置短信服务，不发送短信。账号密码注册登录可用。
- 前端接口仍指向电脑局域网，尚未切换到云端。

## 维护命令（服务器终端执行）

```bash
sudo systemctl status campushelp --no-pager
sudo journalctl -u campushelp -n 80 --no-pager
sudo systemctl restart campushelp
curl http://127.0.0.1:8080/api/health
```

`setup-server.sh` 用于本次新服务器部署；已有环境再次执行前需检查数据库、用户与配置，不宜直接用于其他服务器。
